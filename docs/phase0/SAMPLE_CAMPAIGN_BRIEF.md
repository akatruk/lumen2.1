# Sample Campaign Brief — Soi 11 Soft Opening

> **Historical (2026-07-29):** Sample brief from the Thailand F&B pilot (TikTok primary platform). Current product primary is **China / Douyin**; use this as a structural template only — swap platform/geography/language fields for a Douyin/China campaign.

**Campaign ID (demo):** `camp-2`  
**Product:** Soi 11 Thai Kitchen · Bangkok Bites Co.  
**Category:** Restaurant / F&B  
**Status:** Phase 0 reference brief (use for pilot + sales)

---

## 1. Objective

Drive awareness and foot traffic for the soft opening of Soi 11 Thai Kitchen in Sukhumvit Soi 11. Prioritize authentic food + nightlife creators with Bangkok audience overlap.

## 2. Audience

- Foodies, expats, young professionals, tourists 22–40
- Geography: Bangkok (Sukhumvit / downtown corridor preference)
- Languages: Thai and/or English delivery

## 3. Platforms & deliverables

| Platform | Deliverable | Notes |
| --- | --- | --- |
| TikTok (primary, historical) — Douyin for current China campaigns | 1 short review / walk-in visit | 30–60s preferred |
| Instagram (optional) | 1 Reel or Story set | Tag venue handle when live |
| YouTube | Out of pilot unless creator is YT-native | |

**On-site:** soft-opening visit window (brand provides date options).  
**Publish:** creator’s own account only.

## 4. Messaging pillars

- Shareable plates + open kitchen energy
- Late-night friendly / walk-in culture
- Signature pad kra pao (hero dish)
- Sukhumvit Soi 11 location convenience

## 5. Must include

- Honest reaction to at least one dish + one drink (if of age / appropriate)
- Clear venue name: **Soi 11 Thai Kitchen**
- Soft CTA: visit / location / soft-opening vibe (no hard discount spam unless provided)

## 6. Prohibited claims

- “Healthiest Thai food”
- “Michelin guaranteed” / fake awards
- Medical or diet-cure claims
- Guaranteed wait-time or always-available seating

## 7. Brand safety

- No competing restaurant exclusivity conflict during campaign week (disclose if any)
- No alcohol targeting minors
- No political / hate content adjacent to the post

## 8. Timeline (pilot template)

| Milestone | Target |
| --- | --- |
| Invitation sent | Day 0 |
| Accept / decline | ≤ 48h |
| Brief acknowledged | ≤ 24h after accept |
| Draft / private review link | ≤ 5 days after visit |
| Brand review | ≤ 48h |
| Public post live | ≤ 3 days after approval |
| Performance snapshot | +7 days after publish |

## 9. Compensation (pilot note)

Pilot may run as **barter / soft-opening hospitality** or fixed creator fee — **outside product** until Phase 3. Track agreed terms offline; record only status in-app.

## 10. Success metrics (record in app)

| Metric | Source |
| --- | --- |
| Views | Creator post / manual entry |
| Likes | Creator post / manual entry |
| Comments | Creator post / manual entry |
| Saves (if available) | Platform |
| Publication URL | Creator |
| Time invite→publish | System timestamps |
| Foot-traffic / promo redemptions | Brand manual (optional) |
