# Lumen 网红市集 — 约四分钟旁白（中文）· 0.4.4 线上演示

今天带大家走一遍线上运行的 Lumen 网红市集——赛博玻璃品牌控制台、真实 TikTok 发现、真实产品扫描，以及服务端协作。

在泰国，品牌并不缺粉丝，缺的是真正契合产品的创作者——无论是曼谷 Soi 11 餐厅、泰国护肤、普吉公寓，还是海岛旅游。

粉丝数回答不了真正的问题：这位创作者的内容、语言、受众与品牌安全画像，是否匹配我们正在销售的产品？

因此市集从产品开始，而不是从虚荣指标开始。

先看线上品牌流程。品牌账号登录后，会话保存在服务器。用网址、Brief 与照片名扫描产品，OpenRouter 生成可编辑的产品简历卡——名称、卖点、地域、主题、语言、利益点、禁用宣称与置信度。保存后卡片随账号跨浏览器保留。

带着该产品进入 Discover。Live TikHub 搜索返回真实 TikTok 创作者，并对照简历卡给出可解释的匹配分数与理由。打开档案，把合适的创作者加入短名单——登录状态下同样保存在服务器。

再看协作。邀请创作者参加活动，对方在创作者端接受，系统签发 Brief。确认 Brief、提交成片，批准后在自己的社交账号发布。品牌审核并记录效果。邀请与 Brief 对品牌账号持久保存。

Lumen 仍是视频理解的分析引擎；市集负责品牌、产品、发现、匹配、邀请、Brief 与流程。今天 TikHub 与 OpenRouter 已上线。第三阶段引入合同与支付，第四阶段扩展数据源并从结果中学习。

Lumen 网红市集把视频理解变成活动决策——审慎、透明，并适合泰国餐饮试点。

谢谢。
