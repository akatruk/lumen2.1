# Lumen 网红市集 — 约两分钟旁白（中文）· 抖音 / 中国 主战场

> **说明（2026-07-29）：** 本脚本已更新为当前主要平台——**抖音（中国）**。此前版本描述的是泰国餐饮试点 + 国际版 TikTok，该框架已从当前叙事中退役。详见 `docs/DISCOVERY_AND_DOSSIER.md`。

今天带大家走一遍线上运行的 Lumen 网红市集——赛博玻璃品牌控制台、真实抖音发现、实时产品扫描，以及更诚实的协作体验。

面向中国市场的品牌并不缺粉丝，缺的是真正契合产品的创作者——无论是上海餐厅、国货护肤、生活方式品牌，还是跨境电商新品。

仅看粉丝数回答不了真正的问题。因此市集从产品开始，而不是从虚荣指标开始。

仪表盘侧栏分为 Core 与 More，登录放在页脚。模式徽章显示 Live，含 TikHub 与 LLM。两个主操作引导流程:扫描产品与 Discover 抖音。

用网址、Brief 与照片名扫描产品,OpenRouter 生成产品简历卡。先看决策区——卖点、主题、地域、禁用宣称与置信度;名称、预算与语气收在 Details。

带着该产品进入 Discover。Live TikHub 返回真实抖音创作者,粉丝数非零,并给出可解释理由——触达、互动率、均播、语言与垂类。打开档案时,品牌安全在未分析前显示 Pending Analysis,不会假装 Safe。

创作者端 Act-as 优先列出 TikHub 发现的抖音创作者。切换身份后,首页副标题、邀请与 Brief 跟随该创作者,而不是卡住种子账号。创作者身份就是 Act-as 抖音——没有国际版 TikTok 登录。

Lumen 仍是视频理解引擎;市集负责品牌、产品、发现、匹配与流程。今天 TikHub 与 OpenRouter 已上线——沿用 Strom/lumen 现有账号,没有新建集成。第三阶段引入合同与支付。

Lumen 网红市集把视频理解变成活动决策——审慎、透明,并适合中国 / 抖音试点。

谢谢。
