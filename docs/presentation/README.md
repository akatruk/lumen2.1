# Lumen Influencer Marketplace — Video Presentation Pack (EN)

**Length target:** 7–8 minutes (comfortable inside 5–10)  
**Audience:** stakeholders / investors / agency partners  
**Demo URL:** http://167.71.206.43:3000  
**Creator portal:** http://167.71.206.43:3000/creator  

## Files

| File | Use |
| --- | --- |
| [SCRIPT.md](./SCRIPT.md) | Spoken narration + timing |
| [SHOT_LIST.md](./SHOT_LIST.md) | Screen-record sequence synced to script |
| [slides.html](./slides.html) | Open in Chrome → full screen → present |

## How to record (recommended)

1. Open `slides.html` in Chrome (presenter window).
2. Open demo in a second window (or same machine, switch scenes).
3. Record with OBS / QuickTime:
   - Scene A: slides
   - Scene B: browser demo (brand + creator)
4. Follow `SCRIPT.md` with teleprompter or notes.
5. Export 1080p, 30fps, AAC audio.
