## 2. Что можно / нельзя обещать сейчас

### Можно
- Показать полный demo-нарратив scan → card → ranked Discover → dossier → shortlist.
- Brand **login** и серверное сохранение продуктов **через API** (после hydrate UI — следующий slice).
- Стабильный HTTPS URL для клиентов.

### Нельзя
- «Мы уже ищем live TikTok через TikHub» — пока нет ключа / `DISCOVERY_MODE=live`.
- «AI реально читает ваш сайт» — пока нет OpenRouter key / live scan mode.
- «Всё в облаке» — shortlists, invites, dossiers, campaigns ещё **localStorage**.
- Payments / юр. контракт.

## 3. Следующий бизнес-slice (делаем сейчас)

**Добить G3 для brand core-path без внешних ключей:**

1. Logged-in: **hydrate products** из `GET /api/products` → UI SoT.
2. Logged-in: create/update product → server (синхронно, server id).
3. **Shortlists на сервере** (Prisma + `/api/shortlists`) + hydrate/mutate.
4. Login → hydrate → `/products` / `/shortlists` показывают серверные данные.

**Потом (после ключей или параллельно sales):** включить live TikHub/LLM.  
**Затем B:** invite → accept → brief на persistence.
